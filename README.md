F1 Predicting Race Position From Timing:

This project aims to see if a Formula One race winner can be predicted from Free Practice and Qualifying timing and positions.

I started this project in spring 2026 under time constraints with the majority of the time used on organizing data. My goal was
to learn machine learning more deeply on my own and then apply F1 to it. I was able to successfully load and organize data from
multiple races to use on the model. I started with a simple model, but it does not understand parts of the data, so my next step
will be figuring out if I can change the data or if I have to switch models. I hope to use continue this project in the future
using more complex ML models.
